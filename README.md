
# Java Vector Exercises

This project contains three Java programs developed to practice vector manipulation, loops, conditionals, and basic algorithms.

## Technologies

- Java
- Scanner
- Arrays (Vectors)
- Loops (`for`, `while`)
- Conditional statements (`if`, `else`)
- Bubble Sort

## Exercises

### 1. Vector Sorting and Vowel Counting
- Reads integer values from the user.
- Sorts the vector in ascending order using Bubble Sort.
- Counts the vowels in a name entered by the user.

### 2. Even and Odd Number Transformation
- Reads integer values into a vector.
- Multiplies even numbers by 2.
- Raises odd numbers to the power of 2.
- Displays the modified vector.

### 3. Name Reversal
- Reads a name from the user.
- Converts the name into a character array.
- Reverses the characters and displays the result.

## How to Run

1. Clone or download this repository.
2. Open the project in your preferred Java IDE.
3. Run each Java file separately:
    - `VectorSortVowels.java`
    - `VectorParity.java`
    - `ReverseName.java`
4. Follow the instructions displayed in the console.

## Learning Objectives

- Practice Java arrays and character arrays.
- Use loops and conditional statements.
- Implement a basic sorting algorithm.
- Manipulate and process user input.
